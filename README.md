## Cách cài đặt .

- **git clone https://github.com/DuyKiet04/bando.git**
- **cd bando (project)** => **npm install** (nếu máy đã có vite)
- **npm install (lib)** ví dụ npm install leaflet

## Cách chạy project .

- **npm run dev** => ctrl + click **http://localhost:5173/**

- **npm run build**
